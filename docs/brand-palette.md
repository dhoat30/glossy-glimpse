# Fern Cleaning colour palette

A natural palette built around the green logo, with warm ivory backgrounds and soft sage accents.

| Colour | Hex | Use |
| --- | --- | --- |
| Forest | `#1E5B43` | Primary buttons, headings, links and footer |
| Deep forest | `#123B2C` | Dark section backgrounds and gradient depth |
| Fern leaf | `#699358` | Decorative accents and gradient highlights |
| Soft sage | `#DCE8D2` | Accent buttons, heading highlights and form banners |
| Warm ivory | `#F8F9F5` | Main background and quiet surface areas |
| Botanical charcoal | `#24382E` | Body text |

Supporting colours: `#174A36` for primary hover, `#C9DABB` for sage hover, `#58675E` for muted text, and `#D5DED2` for borders.

Use white text on forest buttons and forest text on sage buttons. Fern leaf is a decorative colour; use forest or charcoal for normal text on light surfaces.

CSS tokens live in `app/tokens.css`. Material UI colours live in `utils/themeSettings.js`; the email template uses matching inline colours for email client compatibility.
